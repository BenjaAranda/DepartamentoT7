# Evidencia T11

Las imágenes muestran un levantamiento 2D sobre referencias originales. No son renders de un modelo 3D terminado.

- [Planta con muros y vanos](planta-muros-vanos.png): 40 paños entre caras, seis puertas y siete ventanas/celosía/paso abierto. Conserva la orientación de la página 20.
- [Puertas y bisagras](puertas-y-bisagras.png): seis ampliaciones con hoja abierta, cerrada, pivote y sentido observado. Los anchos son lecturas, sin certificar el paso libre acabado.
- [Remates y logia](remates-y-logia.png): nicho D3, cambios de espesor, retranqueo baño–cocina, volumen técnico y frente de logia contrastado con la isométrica.
- [Muros](muros.tsv), [vanos](vanos.tsv), [puertas](puertas.tsv), [esquinas](esquinas.tsv) y [control de caras](control-caras.tsv): tablas de datos y evidencia de lectura.
- [Comprobación](comprobacion.json): huellas de entrada/salida, cobertura del catálogo y resultados geométricos.

Entrada de autoría: [t11-trazado.json](../../../architecture/plan/t11-trazado.json). Registro métrico: [t11-registro.json](../../../architecture/plan/t11-registro.json). Generador: `scripts/build-t11-plan.py`.

Las imágenes originales están en [p20-t7](../p20-t7/README.md); no se modifican para producir estas láminas. Los rótulos T11 y el trazado se añaden en archivos derivados independientes. La planta nativa conserva el mobiliario de la fuente; el usuario exige una sola cama en D2 y dos hojas en cada armario final.
