# Evidencia de validación

| Carpeta | Evidencia prevista |
|---|---|
| `orthographic/` | Plano superpuesto, contornos, cotas, áreas y desviaciones; V01–V04. |
| `isometric/` | Arquitectura y mobiliario desde los puntos de inspección; V05 y V11. |
| `collisions/` | Penetraciones, contactos, barridos de puertas y coherencia de proxies; V06, V07 y V10. |
| `routes/` | Recorridos por recinto y casos adversos; V08 y V09. |
| `performance/` | Carga, tiempos de cuadro y dispositivos realmente probados; V12–V14. |
| `releases/` | Manifiesto, revisión, archivos y comprobación de la entrega; V15. |
| `recordings/` | Grabaciones completas locales, excluidas de Git; distribuir las seleccionadas como entregables. |

Los informes y capturas de tamaño razonable se versionarán con el código. Los videos completos y paquetes grandes irán en entregables de versión según `../docs/ALMACENAMIENTO.md`.

Una carpeta vacía no acredita una prueba superada. Cada informe debe identificar revisión, herramienta, resultado, limitaciones y archivos realmente comprobados. Las verificaciones administrativas de T01–T03 se documentan en `../docs/`.
